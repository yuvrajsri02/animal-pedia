About Animal Pedia

Animal Pedia is a simple and informative website created to provide knowledge about different types of animals. It covers various categories such as aquatic animals, reptiles, birds, and mammals, along with their basic characteristics and examples. The purpose of this website is to make learning about animals easy and interesting for everyone. It is designed with a clean layout and user-friendly interface so that users can explore information without difficulty. This project also represents my learning journey in web development, where I have used HTML and CSS to build a structured and visually appealing website.
